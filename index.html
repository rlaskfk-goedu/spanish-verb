프롬프트 워크플로우

생성형 AI로 반응형 스페인어 학습앱 만들기

ChatGPT, Claude, Gemini 등에 아래 단계별 프롬프트를 차례대로 입력하면 이와 동일하거나 더 확장된 스페인어 학습 웹앱을 스스로 구현할 수 있습니다.

1

Step 1: 앱 기획 & 전체 아키텍처 설정 프롬프트

웹앱의 목적, 대상, 사용하는 기술 스택(HTML/Tailwind/JS)의 기본 프레임워크를 요구합니다.

스페인어 동사 변형(Conjugation)을 주어 인칭(Yo, Tú, Él/Ella/Usted, Nosotros, Vosotros, Ellos/Ellas/Ustedes)별로 효과적으로 학습할 수 있는 반응형 웹 애플리케이션을 단일 HTML 파일(Tailwind CSS + Vanilla JS)로 제작하려고 합니다.

[기본 사양]
1. 프론트엔드: HTML5, Tailwind CSS(CDN), JavaScript (ES6)
2. 디자인: 모바일/데스크톱 모두 지원하는 깨끗하고 현대적인 카드 스타일 UX
3. 주요 목적: 초/중급 스페인어 학습자가 반복적으로 인칭별 동사 변화를 연습할 수 있도록 유도.

우선 전체 HTML 구조의 뼈대와 헤더 탭 메뉴(학습 모드, 동사 변형표, AI 가이드)를 갖춘 레이아웃 코드를 작성해 줘.
2

Step 2: 동사 데이터베이스 및 규칙 엔진 설계

규칙 동사(-ar, -er, -ir)와 불규칙 동사(ser, estar, ir, tener 등)를 표현하는 JSON 데이터 구조를 생성합니다.

이제 스페인어 동사 데이터를 관리할 JavaScript 객체 배열(JSON 구조)을 작성해 줘.

[데이터 요구조건]
1. 규칙 동사: -AR (hablar), -ER (comer), -IR (vivir)
2. 주요 불규칙 동사: Ser, Estar, Ir, Tener, Hacer
3. 각 동사 객체에는 다음 항목이 포함되어야 함:
   - id, base(원형), meaning(한국어 뜻), type(-ar, -er, -ir, irregular)
   - conjugations: { yo, tu, el_ella_usted, nosotros, vosotros, ellos_ellas_ustedes }
4. 인칭 대명사의 한국어 설명 표기 (예: Yo = 나, Tú = 너, Nosotros = 우리들)

이 데이터를 바탕으로 특정 주어와 동사 원형이 주어졌을 때 정답 형태를 반환하는 변형 로직 함수를 포함해 줘.
3

Step 3: 다양한 인터랙티브 학습 모드 구현

객관식, 직접 입력, 플래시카드의 3가지 모드를 통한 다양성 부여 프롬프트입니다.

사용자가 지루하지 않게 다양한 방식으로 반복 학습할 수 있도록 3가지 연습 모드를 구현해 줘.

[학습 모드 세부 사양]
1. 객관식 퀴즈 모드: 주어(예: Nosotros)와 동사 원형(예: Comer)이 주어지면, 4개의 오답/정답 선지 버튼 중 알맞은 변형(Comemos)을 선택.
2. 빈칸 입력 모드: 텍스트 입력창에 직접 정확한 스펠링으로 변형된 동사를 입력하고 [확인] 버튼을 누름.
3. 플래시카드 모드: 앞면엔 "주어 + 동사원형", 클릭 시 뒤집어지며 정답 변형 형태 확인 (알아요/몰라요 버튼 제공).

드롭다운 메뉴로 이 3가지 모드를 자유롭게 전환할 수 있도록 JavaScript 로직과 UI를 연결해 줘.
4

Step 4: 게임화(Gamification) & 음성/피드백 기능

동기부여를 위한 연속 정답(Streak), 발음 듣기(TTS), 정답 설명 피드백 기능 추가.

학습 효율성과 재미를 극대화하기 위해 다음 기능들을 추가해 줘.

1. Streak & Score 시스템: 연속 정답 시 🔥 불꽃 스티커와 함께 연속 카운트 증가. 오답 시 0으로 리셋.
2. 스페인어 발음 TTS (Text-to-Speech): Web Speech API(`window.speechSynthesis`)를 활용하여 스피커 아이콘을 누르면 스페인어 발음(es-ES)을 들려주는 기능.
3. 피드백 및 문법 설명: 정답/오답 클릭 시 단순 성공 유무 외에 왜 이 동사 형태가 나오는지 간단한 시각적 피드백과 설명 박스 노출.

이 코드를 기존 코드에 통합해 줘.
5

Step 5: 전체 동사 변형 총정리 참조표 및 UI 다듬기

전체 인칭별 변형을 한눈에 조회할 수 있는 종합 참조 테이블과 UI 완성도 향상.

마지막 단계로, 사용자가 언제든지 특정 동사의 전체 6가지 인칭 변형 형태를 한눈에 볼 수 있는 '동사 변형 참조표' 탭을 완성해 줘.

1. 셀렉트 박스에서 원하는 동사를 선택하면 (Yo, Tú, Él/Ella/Usted, Nosotros, Vosotros, Ellos/Ellas/Ustedes)에 해당하는 변형 표가 테이블 형태로 즉시 업데이트됨.
2. 반응형 모바일 대응: 모바일 화면에서도 테이블이 잘리지 않고 깔끔하게 보이도록 Tailwind 스타일링 적용.
3. 완성된 단일 HTML 파일 전체 코드를 버그 없이 동작하게 제공해 줘.
